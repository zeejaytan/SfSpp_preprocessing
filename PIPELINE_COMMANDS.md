## Complete Processing Pipeline for Pot A

### 1. Environment Setup
```bash
module load MATLAB/2024b_Update_3
module load Apptainer/1.3.3
cd /data/gpfs/projects/punim2657/sfs_preprocessing
```

### 2. Mesh Processing (Convert OBJ → Point Cloud → TPS Surfaces)
```bash
# For each piece 01-08:
for piece in {01..08}; do
  /apps/easybuild-2022/easybuild/software/Compiler/GCCcore/11.3.0/Apptainer/1.3.3/bin/apptainer exec \
    cache/sfs_prep_from_working.sif \
    ./build/mesh_processing_complete A $piece
done
```

### 3. Axis Extraction (MATLAB PotSAC Algorithm) - SLURM Parallel Method
```bash
# SLURM parallel approach (recommended - faster and more reliable):
./submit_axis_jobs.sh           # Submit all 8 pieces in parallel
squeue -u $USER                 # Monitor job progress
./check_axis_results.sh         # Verify completion

# Alternative: Sequential MATLAB approach (slower)
for piece in {01..08}; do
  ./matlab_axis_wrapper.sh A $piece
done
```

### 4. EdgeLine Extraction (Generate Breaklines + Surface_F files)

**SLURM Submission Required** (computationally intensive: ~90 seconds per piece):
```bash
# Submit as SLURM job (recommended approach)
sbatch run_edgeline_extraction.sbatch
```

**Manual Container Execution** (only for testing):
```bash
# Process ALL pieces at once (cannot be done individually)
/apps/easybuild-2022/easybuild/software/Compiler/GCCcore/11.3.0/Apptainer/1.3.3/bin/apptainer exec \
  --overlay /tmp \
  --bind /data/gpfs/projects/punum2657/sfs_preprocessing:/data/gpfs/projects/punim2657/sfs_preprocessing \
  --pwd /data/gpfs/projects/punim2657/sfs_preprocessing \
  cache/sfs_prep_from_working.sif \
  ./build/edgeline_extraction A 8
```

**IMPORTANT NOTES**:
- EdgeLineExtraction processes pieces 1 through N sequentially (use "8" for all pieces)
- Must run in container due to library dependencies
- Processing time: ~12-15 minutes total for 8 pieces
- Requires overlay mount for temporary file write access
- **Use SLURM**: Interactive sessions may timeout

### 5. Organize Clean Dataset (Recommended)
```bash
# Auto-organize all preprocessing outputs into clean dataset structure
./organize_dataset.sh

# This creates: TPS_Dataset_YYYYMMDD/SfS_pp/ with properly formatted files
# - Surfaces/ (16 .xyz files)
# - Breaklines/ (16 .pcd files)  
# - Axes/ (8 .xyz files)
# - Mesh/ (8 .obj files)
```

### 6. Run SFS Fragment Assembly - SLURM Method (Recommended)
```bash
cd /data/gpfs/projects/punim2657/sfs_main

# Method 1: SLURM job with clean TPS dataset (recommended)
sbatch test_clean_tps_relaxed.sbatch

# Method 2: Manual execution with direct dataset binding
/apps/easybuild-2022/easybuild/software/Compiler/GCCcore/11.3.0/Apptainer/1.3.3/bin/apptainer exec \
  --bind /data/gpfs/projects/punim2657/sfs_main:/workspace \
  --bind "/data/gpfs/projects/punim2657/sfs_preprocessing/TPS_Dataset_20250829/SfS_pp:/Dataset/SfS_pp" \
  sfspreproc.sif \
  /workspace/sfspreproc-docker/Hierarchy-Clear 8
```

**Key Advantage**: Direct dataset binding eliminates file copying and ensures data integrity.

## Key Files Generated

### Per Piece Output Files:
- `Pot_A_Piece_XX_Point.pcd` - Point cloud from mesh (Temp/Data/Pot_A/)
- `Pot_A_Piece_XX_Surface_0.xyz` - Outer surface (TPS fitted) 
- `Pot_A_Piece_XX_Surface_1.xyz` - Inner surface (TPS fitted)
- `Pot_A_Piece_XX_Axis.xyz` - 6D axis parameters [pos_x pos_y pos_z dir_x dir_y dir_z]
- `Pot_A_Piece_XX_Breakline_0.pcd` - Outer breakline geometry  
- `Pot_A_Piece_XX_Breakline_1.pcd` - Inner breakline geometry
- `Pot_A_Piece_XX_Surface_F.pcd` - Fracture surface points (generated by EdgeLine extraction)

## Troubleshooting

### EdgeLineExtraction Issues:
1. **Must process all pieces together** - cannot skip to piece N
2. **Requires overlay mount** for temp file write access
3. **Takes ~10-15 minutes total** for all 8 pieces
4. **Generates Surface_F files automatically** when working correctly
