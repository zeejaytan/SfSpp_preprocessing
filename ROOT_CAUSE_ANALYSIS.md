## Why Are Surface Files Different?

The surface files are generated by **MeshPreprocessingHeadless** from the mesh files. Even with identical mesh inputs, different preprocessing parameters produce different surface outputs.

### Key Parameters That Affect Surface Density:

1. **Grid Resolution** - How finely the mesh is sampled
2. **NURBS Sampling Density** - Points sampled from NURBS surface
3. **Point Cloud Decimation** - How much the point cloud is thinned
4. **Normal Estimation Radius** - Affects local geometry interpretation

### Evidence from Code:

```cpp
// From mesh_processing_headless.cpp:360
AdaptiveParams computeAdaptiveParams(int num_points, double avg_spacing_m) {
    // Radius searches: 3-5× average point spacing
    ...
}
```

Different adaptive parameters → different point sampling → different surface densities.
